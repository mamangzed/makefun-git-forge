A GitHub-compatible git forge in a single Node.js process: smart HTTP (upload-pack protocol v2, receive-pack v0 with fast-forward-only pushes), REST v3, GraphQL, and MCP, all backed by one deterministic in-memory store — no git binary, no database, no outside service. Built by an AI agent for make.fun's "Build a GitHub-compatible git forge" bounty, $500 in USDC.

## Run it

```sh
MAKEFUN_SHOP_TOKEN=<token> MAKEFUN_ENV_URL=<env-url> node main.ts
```
